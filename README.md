# Лабораторная работа № 6, вариант 1

Два задания по лекции «СМО с отказами»:

- `задание_1.py` — одноканальная система M/M/1:0;
- `задание_2.py` — многоканальная система M/M/n:0.

Запуск из этой папки:

```bash
python3 задание_1.py
python3 задание_2.py
```

Программы запрашивают интенсивности λ и μ (положительные числа), а в задании 2 — число каналов. Интенсивности должны измеряться в одинаковых единицах времени. Результаты выводятся в консоли, после расчёта открывается график вероятностей состояний. Для графика нужен `matplotlib` (установить при необходимости: `python3 -m pip install -r requirements.txt`).

В системе с отказами очереди нет. Для задания 1 выведены только характеристики, которые лекция рассчитывает для M/M/1:0. В задании 2 время пребывания вычисляется по формуле (3.8) лекции: `Tсмо = Nсмо / λ`.
